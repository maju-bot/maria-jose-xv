# MARIA JOSE · Mis XV años

Invitación web interactiva para los XV años de MARIA JOSE.

## Publicar gratis con GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube **todo el contenido de esta carpeta**, manteniendo la carpeta `assets`.
3. En el repositorio entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`.
6. Guarda y espera a que GitHub publique el sitio.

El archivo `index.html` debe quedar en la raíz del repositorio.

## Nota

La invitación usa Google Fonts para la tipografía de los padrinos cuando hay conexión a Internet. El resto de los recursos principales está incluido en el repositorio.
